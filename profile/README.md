<p>同一个「住宅 IP 代理」的名目，报价能从每月十几元到几百元不等，原因不是谁在宰客，而是五个参数没对齐：池子多大、重复率多高、单价按什么计、切换要不要钱、交付用什么形式。这五个数任意一个变动，最终的单号月成本能差两三倍。这篇把它们逐项列成一张参数说明书，每项给出常见取值区间、该向供应商问哪句话、以及这一项对成本的实际影响，最后给一个把参数代进公式就能算出单号月成本的算法，附两个算例。</p>

<h2>一、五个参数决定报价，先看清单</h2>
<p>询价时最有效的一句话不是「多少钱」，而是「你们的池子多大、重复率多少、切换怎么算」。这三问一出，销售就知道你不是第一次买。</p>
<h3>五个参数</h3>
<p>池规模，指可分配的不重复地址总量；重复率，指同一地址在多久内会被分配给第二个客户；单价口径，是按条、按流量还是按小时；切换成本，指更换地址是否收费、收多少；交付形式，是隧道、账密还是 API 提取。前两个决定资源质量，后三个决定账怎么算。</p>
<h3>哪些能验、哪些只能信</h3>
<p>单价和交付形式可以直接验，看合同和文档即可。池规模可以间接验：连续七天每小时提取一次地址，统计去重数量，能大致估出可用池的下限。重复率几乎无法自验，只能靠合同条款约束，所以这一项一定要写进合同，而不是听口头承诺。</p>

<h2>二、池规模与重复率：两个数必须一起问</h2>
<p>只问池子大不大没有意义。一个有十万地址但重复率高的池子，实际体验可能不如一个五千地址但分配严格的池子。</p>
<h3>池规模怎么看</h3>
<p>看两个维度：总量与地区分布。总量决定你能不能同时拿到很多不重复地址；地区分布决定你能不能覆盖注册地。常见的中小供应商，单地区可用住宅地址在几百到几千条，跨十几个国家；大一些的能到几万条。数字越大越好，但地区分布不均的话，热门地区的实际可用量可能只有总量的一小部分。</p>
<h3>重复率的算法</h3>
<p>自己算一个近似值：在同一地区连续提取 100 个地址，统计其中被分配到两次以上的比例，以及两次分配的最短间隔。间隔小于 24 小时的，视为高重复。这个测试花不了多少时间，但能避免买到「看起来很大、实际都在轮转」的池子。</p>

<h2>三、单价口径：按条、按流量、按小时差在哪</h2>
<p>三种口径不是简单的换算关系，它们对应三种不同的使用形态，选错口径比选贵供应商更费钱。</p>
<h3>三种口径的适用</h3>
<p>按条计费：每条地址每月固定价，常见 80 至 200 元（仅供参考），适合长期固定出口、每天都要用的账号。按流量计费：常见 3 至 8 元每 GB（仅供参考），适合低频、流量小的场景，但要注意住宅出口的流量消耗往往比想象中大，一次页面加载就可能几十 MB。按小时计费：常见 1 至 3 元每小时（仅供参考），适合集中使用几天到两周的项目。</p>
<h3>怎么问价才不吃亏</h3>
<p>问三句：超出套餐部分按什么价计、是否有最低消费、以及并发隧道数是否单独收费。第三句最关键，很多报价里的「每条」只含一个隧道，多开一个加钱，而实际使用中一个账号往往需要两到三个隧道做隔离。</p>

<p>把三句问完，再让供应商报一个「三十个账号、每条一个号、月均用量中等」的具体方案价，这样拿到的数字才有可比性。</p>

<h2>四、切换成本：换一次出口付多少</h2>
<p>这一项在报价单上往往不写，但它决定了账号受限之后重来的成本结构。</p>
<h3>三类切换成本</h3>
<p>第一类是直接费用，换一条地址收 5 至 20 元不等，有的供应商每月给三次免费额度。第二类是时间成本，换线后需要重新观察三到七天才能确认稳定，这段时间账号处于半可用状态。第三类是机会成本，换线期间如果正好有交付节点，损失按业务算。三类里只有第一类出现在账单上，后两类要靠自己折算。</p>
<h3>谈判要点</h3>
<p>把「每月免费更换次数」写进合同，常见可谈到 3 至 5 次；把「同城同运营商替换」作为选项，价格高一些但连续性更好；以及约定「因供应商侧地址回收导致的更换不计费」。最后一条最重要，因为它把不可控的成本转移给了对方。</p>

<h2>五、把参数代进公式，得出单号月成本</h2>
<p>公式不复杂，难的是把每一项都填上真实数字。</p>
<h3>公式</h3>
<p>单号月成本 =（地址月费 + 月均更换次数 × 单次更换费 + 月均更换次数 × 观察天数 × 日均人工成本）÷ 账号数 + 账号订阅成本分摊。注意第三项容易被漏掉，但它常常是最大的一块。</p>
<h3>两个算例</h3>
<p>算例一：三十个账号，每条地址月费 120 元且一号一条，月均更换 2 次、每次 10 元，观察 5 天、日均人工 80 元。地址成本 3600 元，更换费 60 元，观察人工 800 元，合计 4460 元，单号约 149 元。算例二：同样三十个账号，改用共享池按流量计费，月流量 60 GB、单价 5 元，地址成本 300 元，但月均更换升到 8 次、观察人工 3200 元，合计 3580 元，单号约 119 元。看起来第二种便宜，但如果把停用期间无法交付的损失算进去，多数团队会选第一种。</p>

<h2>常见问答</h2>
<h3>池子大就一定好吗？</h3>
<p>答：不一定。要看热门地区的实时可用量和重复率。一个总量很大但热门地区长期满载的池子，实际拿到的往往是边缘地区的地址，和账号注册地对不上，反而更麻烦。</p>
<h3>按流量计费是不是更便宜？</h3>
<p>答：只在用量很小时更便宜。住宅出口的流量开销容易被低估，图片、脚本、字体都算流量。按一个月 60 GB 估算，单价 5 元就是 300 元，和一条独享线路的价格已经很接近，但稳定性和独享度差很多。</p>
<h3>账号受限之后换新出口重来，算不算划算？</h3>
<p>答：要看受限原因。如果是环境侧误判，换到更匹配的地址有意义；如果是账号行为本身的问题，换出口并不能解决，且平台对规避处置有明确条款。处理方式应以平台给出的流程为准。</p>
<h3>合同里最该写清哪一条？</h3>
<p>答：地址回收与更换的计费规则。这一条决定了后续成本的可控程度，比单价本身更值得花时间谈。</p>

<h2>合规提示</h2>
<p>本文讨论的是资源采购与成本核算，不涉及规避平台风控。账号受限时应按平台提供的申诉与核验流程处理，不得通过更换出口等方式规避平台处置。</p>
<p>采购前请核实服务商的经营资质与地址来源合法性，合同中明确用途范围与数据合规责任，避免使用来源不明或用途受限的地址。</p>
